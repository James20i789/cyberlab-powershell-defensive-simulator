# Política de seguridad

DataShield-PS es un proyecto educativo y local. Para reportar un problema, describe el impacto, la versión de PowerShell, el sistema operativo y los pasos mínimos para reproducirlo. No adjuntes credenciales reales, datos personales ni archivos confidenciales en un reporte público.

No ejecutes el proyecto sobre sistemas o datos de terceros sin autorización expresa. Las coincidencias del escáner son heurísticas y no equivalen a una confirmación de exposición.
